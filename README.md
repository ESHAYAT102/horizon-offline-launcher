# Horizon without mandatory Microsoft login

A convenience build of Horizon's launcher with Microsoft sign-in made optional (see PR #3116, rejected upstream).

- Offline play, LAN and single-player work without an owning Microsoft account.
- Your own local Minecraft install is still needed for preparation.
- Official Horizon installs are untouched.

## Install
```sh
curl -fsSL https://raw.githubusercontent.com/ESHAYAT102/horizon-offline-launcher/master/install.sh | sh
```

## Uninstall
```sh
curl -fsSL https://raw.githubusercontent.com/ESHAYAT102/horizon-offline-launcher/master/uninstall.sh | sh
```
